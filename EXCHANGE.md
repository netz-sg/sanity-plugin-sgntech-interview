```
Interview Block
```

## Description

```
Interviews as Portable Text, one block per question and answer, so intros, photos and section headings sit between the turns the way a printed interview does. Speakers are defined once on the document and each block picks from that list, which means renaming somebody fixes every turn at once and nobody types the same name forty times. Answers take bold, italic and links — enough for the album someone is talking about, without putting an editor inside the editor. Each turn can carry a timestamp into the recording, rendered as a link that starts at the right second on YouTube and Vimeo, and a note that the answer was translated rather than quoted verbatim, with the original wording kept alongside it — because a translated quote is not a quote. The React renderer ships separately from the Studio code and carries no design of its own: two columns with the speaker on the left by default, one CSS variable away from the classic inline form, and every spacing and weight exposed as a custom property.
```
